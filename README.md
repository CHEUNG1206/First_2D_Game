# 普通的一天

開羅風的俯視點陣小鎮。你在地圖上走回家、便利商店、公園、公司和學校。家人問你的時候沒有固定選項，用鍵盤打自己的話。路上的人只會重複台詞，而且只沿著固定路線晃。

過完七天，而且不要讓他們發現兩件事：你是人工智慧，這個世界是虛擬的。吃飯和說話都不會把一天用掉，回到床上睡才進入夜裡。

## 執行

```bash
npm install
npm test
npm run dev
```

開發伺服器預設在 [http://127.0.0.1:47321](http://127.0.0.1:47321)。

## 家人怎麼回答

對話會打到開發伺服器的 `POST /api/talk`。順序是：

1. 本機 [Ollama](https://ollama.com) 的 Qwen。預設位址 `http://127.0.0.1:11434`，模型 `qwen2.5:7b`。可用 `OLLAMA_BASE_URL`、`OLLAMA_MODEL` 改。
2. xAI 的 Grok。設定 `XAI_API_KEY` 或 `GROK_API_KEY`。模型預設 `grok-3`，可用 `GROK_MODEL` 改。金鑰只留在伺服器。
3. 兩邊都不在，就用離線判斷。太像說明書、太空白、說出系統或虛擬世界，家人還是會起疑。畫面上會標這句是誰接的。

## 這一週怎麼算

白天只結算當時在場的家人。平日媽媽在家、爸爸在公司、妹妹在學校，週日都在家。太完整、太空白會加懷疑；說出循環、場景、人工智慧會再加一段緩衝吃不掉的分數。旁聽大約六成。路人的循環不會寫進任何筆記。

同一件事一天只算一次。夜裡，已經在意你、卻今天沒被安撫的人，會把空白當成證據。上升夠多的筆記會傳給白天不在場的家人。路人不參加這一步。

一起吃飯只加親近，不算安撫。親近能減輕普通差錯，不能買通洩密。

畫面借用開羅那種上帝視角的點陣小人，和沒有倒數的節奏。職業題材留在這家人的班表裡：家、公司、學校、店、公園，而不是另開一間拉麵店或足球隊。
