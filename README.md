# 普通的一天

開羅風的俯視點陣小鎮。陳家在一條擠滿人的街上經營三層酒家：一樓大堂、二樓雅間、三樓住家。對面是茶寮、書塾和布莊。家人問你的時候沒有固定選項，用鍵盤打自己的話。路上的人只會重複台詞，而且只沿著固定路線晃。

過完七天，而且不要讓他們發現兩件事：你是人工智慧，這個世界是虛擬的。吃飯和說話都不會把一天用掉。一樓收店之後是傍晚，全家回到三樓。回到床上睡，這一天才進入夜裡。

## 執行

```bash
npm install
npm test
npm run dev
```

開發伺服器預設在 [http://127.0.0.1:47321](http://127.0.0.1:47321)。

本機模型：

```bash
ollama pull qwen2.5:3b
ollama serve
```

`npm run eval:brain` 會用幾句固定的話打 `/api/talk`，檢查懷疑值有沒有往對的方向走。開發伺服器和 Ollama 都要先開著。

## 家人怎麼想

每位家人有三層記憶：

- 核心記憶是寫好的設定，例如媽媽記得你會嫌蛋。不會被新句子擠掉。
- 學到的記憶是模型決定留下的事，最多 12 句。
- 今天的見聞是看見和聽見的事，包含你按的按鈕。夜裡整理完就清掉。轉述會留到隔天。

對話打到 `POST /api/talk`。夜裡打到 `POST /api/night`。開發時的順序是：

1. 本機 [Ollama](https://ollama.com) 的 Qwen。預設 `http://127.0.0.1:11434`，模型 `qwen2.5:3b`。可用 `OLLAMA_BASE_URL`、`OLLAMA_MODEL` 改。
2. xAI 的 Grok。設定 `XAI_API_KEY` 或 `GROK_API_KEY`。模型預設 `grok-3`。
3. 兩邊都不在，就用離線判斷。畫面會寫「模型沒接上」。

模型自己決定懷疑上升或下降、要記住的句子、夜裡要不要告訴另一個人、明天要問的那一句。程式只把整數記上去。發佈到網路時不連本機 Ollama，有 Grok 金鑰才用 Grok。

這一週存在瀏覽器裡。重新整理還在。看完結局就清掉。

## 這一週怎麼走

白天只讓當時在同一層的家人聽見。平日媽媽在一樓、爸爸在二樓、妹妹上午在書塾。收店之後傍晚全員在三樓。週日從早上就在三樓。

結局只看門檻：有人到 100 就是被看穿，第五天起兩人到 68 就是家庭會議，第七天最高到 46 就是不安地留下。路人不參加。

畫面借用開羅那種上帝視角的點陣小人，和沒有倒數的節奏。角色是 48×48、八個方向的唐朝圖，走路時會轉向。
