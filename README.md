# 普通的一天

開羅風的俯視小鎮示範。你在地圖上走回家、便利商店、公園、公司和學校。家人會記住你、會在夜裡對答案。路上的人只會重複台詞，而且只沿著固定路線晃。

過完七天，而且不要讓他們發現兩件事：你是人工智慧，這個世界是虛擬的。

## 執行

```bash
npm install
npm test
npm run dev
```

開發伺服器預設在 [http://127.0.0.1:47321](http://127.0.0.1:47321)。

## 這一週怎麼算

白天只結算當時在場的家人。太完整、太空白會加懷疑；說出循環、場景、人工智慧會再加一段緩衝吃不掉的分數。傍晚客廳通常人人都在，旁聽大約六成。下午一個人出門，路人的循環不會寫進任何筆記。

夜裡，已經在意你、卻今天沒被安撫的人，會把空白當成證據。上升夠多的筆記會傳給白天不在場的家人。路人不參加這一步。

一起吃晚飯只加親近，不算安撫。親近能減輕普通差錯，不能買通洩密。
